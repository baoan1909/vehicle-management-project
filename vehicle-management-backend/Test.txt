* Vehicle Type

POST /api/catalog/vehicle-types
Tạo mới vehicle type

PUT /api/catalog/vehicle-types/{vehicleTypeId}
Cập nhật vehicle type

GET /api/catalog/vehicle-types
Lấy danh sách, có thể truyền ?isActive=true hoặc ?isActive=false

GET /api/catalog/vehicle-types/{vehicleTypeId}
Lấy chi tiết theo id

DELETE /api/catalog/vehicle-types/{vehicleTypeId}
Xóa mềm, thực tế là set isActive = false

* Card

POST /api/access-control/cards

	{
	  "cardNumber": "C002",
	  "uid": "RFID-REGISTERED-002",
	  "cardTypeId": "42000000-0000-0000-0000-000000000001",
	  "vehicleTypeId": "40000000-0000-0000-0000-000000000002"
	}
	
Ví dụ không truyền vehicleTypeId:

	{
	  "cardNumber": "V002",
	  "uid": "RFID-VISITOR-002",
	  "cardTypeId": "42000000-0000-0000-0000-000000000002"
	}
PUT /api/access-control/cards/{cardId}

	{
	  "cardNumber": "C002",
	  "uid": "RFID-REGISTERED-002",
	  "cardTypeId": "42000000-0000-0000-0000-000000000001",
	  "vehicleTypeId": "40000000-0000-0000-0000-000000000003"
	}
	
PATCH /api/access-control/cards/{cardId}/status

Block card:

	{
	  "status": "BLOCKED",
	  "blockedReason": "Tam khoa de kiem tra"
	}
	
Mở block về AVAILABLE:

	{
	  "status": "AVAILABLE"
	}
	
Đánh dấu mất thẻ:

	{
	  "status": "LOST"
	}
	
Đánh dấu hỏng:

	{
	  "status": "DAMAGED"
	}
	
Cho nghỉ hưu thẻ:

	{
	  "status": "RETIRED"
	}
	
GET /api/access-control/cards

Các kiểu filter:

	/api/access-control/cards
	/api/access-control/cards?status=AVAILABLE
	/api/access-control/cards?cardTypeId=42000000-0000-0000-0000-000000000001
	/api/access-control/cards?vehicleTypeId=40000000-0000-0000-0000-000000000002
	/api/access-control/cards?keyword=C00
	/api/access-control/cards?status=AVAILABLE&keyword=RFID
	GET /api/access-control/cards/{cardId}

	DELETE /api/access-control/cards/{cardId}

Lưu ý:
DELETE là retire, không xóa cứng
nếu card đang còn trong flow sống thì sẽ báo lỗi business
